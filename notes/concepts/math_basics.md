# Math Basics for LeetCode

Often, problems can be solved more efficiently using mathematical properties rather than complex data structures.

## Common Tricks
- **Modulo Operator (%)**: Used to get the last digit of a number (`num % 10`).
- **Integer Division (//)**: Used to remove the last digit of a number (`num // 10`).
- **Number Reversal**: `reversed_num = reversed_num * 10 + last_digit`.
- **Prime Numbers**: Sieve of Eratosthenes for finding primes.
- **GCD/LCM**: Using the Euclidean Algorithm.
