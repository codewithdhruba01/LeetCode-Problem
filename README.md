# LeetCode Practice Repository

Welcome to my personal LeetCode solutions repository! 🚀

This repository is dedicated to tracking my progress in solving LeetCode problems. It serves as a resource for revision, understanding different algorithms, and maintaining a consistent practice schedule.

## 📂 Repository Structure

The solutions are organized by **Topic** and **Difficulty** to make revision easier.

```
LeetCode-problem/
├── problems/
│   ├── topics/                  # Problems categorized by topic (e.g., Arrays, Strings)
│   │   ├── arrays/
│   │   ├── strings/
│   │   └── ...
│   ├── easy/                    # Problems categorized by difficulty (Easy)
│   ├── medium/                  # Problems categorized by difficulty (Medium)
│   └── hard/                    # Problems categorized by difficulty (Hard)
├── templates/                   # Code templates for faster development
└── notes/                       # Revision notes and key concepts
```

## 🚀 How to Run

Most solutions are self-contained Java files with a `main` method for testing.

1.  Navigate to the problem directory.
2.  Compile the Java file:
    ```bash
    javac Solution.java
    ```
3.  Run the solution:
    ```bash
    java Solution
    ```
