# Revision Notes: Happy Number

## Core Concept
- **Cycle Detection**: The sequence of numbers generated by the sum of squares of digits will either reach `1` or enter a cycle.
- **Floyd's Algorithm**: Use two pointers (`slow` and `fast`) to detect the cycle without using extra space (like a `HashSet`).

## Algorithm Logic
1. `slow` moves 1 step: `slow = getNext(slow)`
2. `fast` moves 2 steps: `fast = getNext(getNext(fast))`
3. If they meet, they are in a cycle.
4. If `fast` reaches `1`, the number is "happy".

## Key Helpers
- `getNext(n)`: Standard digit extraction using `% 10` and `/ 10` to calculate the sum of squares.

## Why Floyd's over HashSet?
- **Space Efficiency**: Floyd's uses `O(1)` space, whereas a `HashSet` would use `O(number of unique values in sequence)` space.
- Both have similar time complexity, but Floyd's is more interview-friendly for "constant space" constraints.

## Common Pitfalls
- **Infinite Loop**: Not having a termination condition for the `while` loop when a cycle is detected.
- **Digit Extraction**: Mixing up `%` (remainder) and `/` (quotient).

## Complexity
- **Time Complexity**: `O(log N)` — Finding the next number takes `O(log N)` time (proportional to digits), and the number of steps is relatively small.
- **Space Complexity**: `O(1)` — No extra data structures used.
